Easy picture guide

How to use
Site Launchpad

A very simple manual. Short words. Real pictures from the app. Orange numbers show you exactly where to look and click.

What is Launchpad? Launchpad is a website factory. You put in a business name, pictures, and words. Then you preview the site. Then you launch it so the world can see it.
Who is this for? Anyone who can click a mouse. If you can play a simple computer game, you can follow this book.
How the pictures work Each orange circle is a number. Match that number to the list under the picture. That is the button or box we mean.
The big rule Do one client at a time. Finish the steps in order. Green means done. Blue means “do this next.”
Think of it like building a lemonade stand First you name the stand. Then you pick colors. Then you add photos. Then you write the signs. Then you open the door. Launchpad is the same idea, but for a real website.

3. Add a new client

A “client” is one business. One client = one website. You only need the business name to start. You can add the phone and address later.

  1. On the Clients page, click the blue + New client button.
  2. Type the business name in the box. Example: Paradise Spas.
  3. Click + Create client.
  4. Launchpad takes you into that client’s workspace.
1 2 3
1
Back arrow + Clients. Changed your mind? Click here to go home without making a client.
2
Business name box. Type at least 2 letters. The gray words inside are only an example.
3
+ Create client. Saves the new client and opens their page.
Do not delete by accident On the client list, the ⋯ menu can delete a client. Deleting removes that website project. Only do this if you are sure.

After you open a client, the top of the page grows extra buttons. This is the workspace. The first tab is Overview. It is the report card and the treasure map.

Left sidebar client list When you are inside a client, the left menu also shows your clients. Click another name to switch. The search box finds a name fast.

5. Configuration is the worksheet

Click the Configuration tab. This is where you fill in the website. There are 5 mini-steps across the top. Each one has a tiny progress bar. Green means that mini-step is finished.

Launchpad saves by itself after you type. You usually do not need a Save button. If you see Save failed, click Try again.

7. Media — logos and photos

Websites need pictures. Media is the photo room. Left side = all the picture slots. Right side = the one slot you picked, so you can replace it or write alt text.

1 2 3 4 5
1
Add photos. Upload JPEG, PNG, or WebP pictures. Keep each file under 20 MB.
2
Filters. All, Missing, Brand, and other groups. Missing means “this slot still needs a picture.”
3
Photo tiles. Navigation logo, footer logo, favicon (tiny browser-tab icon), social share image, category photos, and marketing photos.
4
Replace / Remove. Change the picture in the selected slot, or take it out.
5
Alt text. A short sentence that says what is in the picture. This helps people who cannot see the image, and it helps search.
Pictures Launchpad cares about most You really need a header logo, footer logo, favicon, and a wide social-share image. Category photos matter for every product group you turned on. If Launch later says an image is missing, come back here and upload it again.

Content is the writing and the menu. Customers will click these links and read these words.

2
Drag handle. The six dots. Hold and drag to change menu order. Up and down arrows also move a row. The trash can deletes it.

What else is on Content

  • Categories — turn on only the products this client sells: hot tubs, swim spas, saunas, cold plunge, massage chairs. Fill the words for the ones that are on.
  • Financing — a switch. Leave it off unless the client really has a lender and approved words.
  • Homepage sections — building blocks of the home page: hero, reviews, FAQ, gallery, visit us, and more. Turn a block on, fill its boxes, drag to change order.

10. Integrations — the secret keys

This tab stores keys the website and future funnels share. Orange means “still needed.” You only must fill keys for tools you turned on.

1 2 3 4

2

11. Pages — the site map

You do not invent new page types here. The template already decided which pages exist. This screen is a map. Each row tells you if that page is ready, and which Configuration box owns the words.

1 2 3 4

Count cards. How many template pages, how many are ready, how many need a fix, how many homepage blocks are visible.

12. Launch — look, then go live

This is the last room. You do not jump here first. Overview will send you here when the other steps are ready. On Overview, Launch is the last item on the Build path.

1 2
1
When the next step says Launch, click Continue.
2
Or open the last Build path row and click Open Launch.

Do these three jobs, in this order

JobWhat it meansWhat you click
1. Preview Launchpad builds a practice website. Only your team should look at it. It is a dress rehearsal. On Launch: the Preview card button. Or the top-right Generate Preview / Open Preview button.
2. Check and approve Open the practice site. Click around. If it looks right, approve it. Approving says “this copy may go to the real world.” Approve preview on the Preview card.
3. Publish The approved practice site becomes the live website. Later you can click Connect live domain so the nice name (like harborandheatspas.com) points at it. Publish on the Production card. If it is already on a temporary address, use Connect live domain.

While preview or publish is working you will see steps like Prepare, Build, Deploy, Live. Wait. Do not click over and over. If it fails, read the red or orange notice, fix the thing it names, then Retry.

Launch will stop you if something is missing Common blockers: empty required Basic info, missing logos, no visible homepage sections, or missing secret keys. Each blocker has a Fix link. Follow it, fill the box, come back to Launch.
Site URL must be real before a custom domain In Basic info, Site URL needs to be a real https address, not example.com. If Launch says it cannot connect the live domain, fix that URL first.

The Actions menu

Top right, next to Preview. It can open New client, Configuration, Integrations, and Open live site (only if one exists).

If something looks broken

  • Gray bars that never go away — the list is still loading. Wait, or click Try again.
  • Choose a client — pick a name in the left client list, or go to Clients and click Continue.
  • Website configuration could not be loaded — click Try again. If it keeps failing, the database or internet is unhappy. Ask a teammate.
  • Preview is out of date — you changed the worksheet after the last practice site. Generate Preview again, then approve again, then publish again.

14. A first-time walk-through

Do this the first time you use Launchpad. Check each box in your head as you go.

  1. Open Launchpad. You should see the Clients list and the rocket.
  2. Click + New client. Type the business name. Click Create client.
  3. On Overview, click Continue (or open Build path step 1).
  4. Fill Basic info: name, site URL, phone, email, address, hours.
  5. Open Branding. Pick a theme and a font pair.
  6. Open Media. Add the header logo, footer logo, favicon, and share image. Add category photos for groups you sell.
  7. Open Content. Set the menu. Turn on the right product groups. Turn on homepage blocks and write the words.
  8. Look at Pages. If a row says Attention, click its owner button and finish it.
  9. Open Technical. Turn on only the tools you really use. Then open Integrations and paste the required keys.
  10. Click Generate Preview. Wait. Open the practice site. Click around like a customer.
  11. Go to Launch. Approve the preview when it looks right.
  12. Click Publish. When it is live, use Connect live domain if the Site URL is the real customer domain.
Green / Complete That part matches what Launchpad needs. You can still edit it later. If you edit after a preview, make a new preview.
Orange / Needs attention Something is empty or wrong. Read the little message under the box. Fix that one thing. Do not guess.
