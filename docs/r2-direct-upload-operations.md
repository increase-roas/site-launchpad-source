# R2 direct-upload owner setup

Complete these steps only in a separately approved production infrastructure phase.

1. Create one Cloudflare R2 bucket using Standard storage.
2. Create an application token scoped to that bucket with Object Read & Write permission.
3. Configure bucket CORS for the exact Vercel preview and production origins:
   - allowed method: `PUT`
   - allowed header: `Content-Type`
   - exposed header: `ETag`
4. Add an object lifecycle rule that expires objects under `tmp/` after about one day.
5. Connect a production custom asset domain to the bucket.
6. Keep the `r2.dev` development URL disabled for production traffic.
7. Do not expose bucket listing.
8. Store `R2_ACCOUNT_ID`, `R2_ACCESS_KEY_ID`, `R2_SECRET_ACCESS_KEY`, `R2_BUCKET`,
   and `R2_PUBLIC_ASSET_BASE_URL` only in Vercel environment variables.

The application token must never be placed in browser code. Browser uploads use short-lived,
content-type-bound presigned `PUT` URLs generated by the authenticated server.
